# SKYPLUS MONEY — API & Integrations

## Active Integrations (Phase 1 & Phase 2)

| Integration | Library / Version | Purpose | Configuration Source |
|---|---|---|---|
| **Firebase Authentication** | `firebase-bom:35.1.0` (`firebase-auth`) | Authoritative UID identity & Google credential exchange (`GoogleAuthProvider.getCredential`) | `app/google-services.json` (`skyplus-money`) |
| **Jetpack Credential Manager** | `androidx.credentials:1.5.0`, `credentials-play-services-auth:1.5.0` | System Google account selection & credential state teardown | Android system + Google Play Services |
| **Google ID Library** | `com.google.android.libraries.identity.googleid:1.1.1` | `GetSignInWithGoogleOption` + `GoogleIdTokenCredential` parsing | `@string/default_web_client_id` (generated by `google-services` `4.5.0`) |
| **Room Database + KSP** | `androidx.room:2.7.1` (`room-runtime`, `room-ktx`, `room-compiler`) | Offline-first encrypted financial accounts, transactions, detection events, mapping rules | Local SQLite DB (`skyplus_money_encrypted.db`, v2) |
| **SQLCipher for Android** | `net.zetetic:android-database-sqlcipher:4.5.4`, `androidx.sqlite:sqlite-ktx:2.4.0` | AES encryption of local Room financial database via Android Keystore 256-bit passphrase | `DatabasePassphraseProvider` + `DatabaseModule` |
| **Android NotificationListenerService** | Android Platform API (`BIND_NOTIFICATION_LISTENER_SERVICE`) | User-consented on-device detection of financial alerts from allowlisted apps | `SkyplusNotificationListenerService` + `AndroidManifest.xml` |
| **Jetpack DataStore** | `androidx.datastore:datastore-preferences:1.1.7` | Theme preference, UID-isolated legal consent records, and smart detection settings | Local encrypted/private app storage |

## Manifest Permissions & Services
- `android.permission.INTERNET` (install-time permission required by Firebase Authentication).
- `SkyplusNotificationListenerService` bound with `android.permission.BIND_NOTIFICATION_LISTENER_SERVICE` (explicit user opt-in required via Android Notification Access settings).
- **SMS Permissions (`READ_SMS`, `RECEIVE_SMS`):** Intentionally **NOT declared** due to Google Play's SMS & Call Log Permissions Policy restricting SMS permissions to Default SMS Handlers.
